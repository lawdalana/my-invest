## Color Indicators

### Price Change Indicators
```
▲ +2.5%  ← Green (Success color)
▼ -1.3%  ← Red (Danger color)
─ 0.0%   ← Gray (Neutral)
```

### Status Badges
```
[Active]    ← Blue background
[Triggered] ← Green background
[Paused]    ← Orange background
[Inactive]  ← Gray background
```

**Design Notes:**
- All measurements in pixels unless specified
- Use 8px grid system for spacing
- Border radius: 6-8px for cards, 4px for buttons
- Transitions: 150ms ease for most interactions
- Focus states: 2px outline with 2px offset
